# CTF 문제 모음 (CTF Challenge Repository)

본 저장소는 CTF (Capture The Flag) 문제들을 개발하고 관리하기 위한 공간입니다.

## 기본 원칙

- 문제 이름: 영어로 시작해야 하며, 영어 대소문자, 숫자, _ (언더스코어)만 사용해야 합니다. 문제 이름은 중복될 수 없습니다.

- .gitignore: 루트 디렉토리에 공통 .gitignore가 있습니다. 만약 특정 문제 폴더에만 적용되어야 하는 규칙이 있다면, 해당 문제 폴더 내에 .gitignore 파일을 개별적으로 작성합니다.

## 기여 방법

본 저장소는 체계적인 브랜치 전략과 커밋 규칙을 따릅니다.

기여에 관심이 있으신 분은, 저장소 루트에 있는 [기여 가이드](CONTRIBUTING.md) 파일을 반드시 숙독하신 후, 해당 워크플로우를 준수해 주시길 바랍니다.
